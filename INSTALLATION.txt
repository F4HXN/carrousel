📦 INSTALLATION
═══════════════════════════════════════════════════════════════

Méthode 1 : Upload du dossier
────────────────────────────────────────────────────────────────
1. Uploadez le dossier "carrousel-sites-pro" dans :
   /wp-content/plugins/

2. Allez dans WordPress : Extensions > Extensions installées

3. Activez "Carrousel Sites Pro"


Méthode 2 : Upload ZIP
────────────────────────────────────────────────────────────────
1. Compressez le dossier en ZIP

2. Dans WordPress : Extensions > Ajouter > Téléverser

3. Sélectionnez le ZIP et cliquez sur "Installer"

4. Activez le plugin


🚀 UTILISATION
═══════════════════════════════════════════════════════════════

Étape 1 : Configurer vos sites
────────────────────────────────────────────────────────────────
➜ Allez dans le menu : Carrousel Sites

➜ Ajoutez vos sites avec :
  • URL complète (https://...)
  • Titre du site
  • Icône (emoji)
  • Description (optionnel)

➜ Cliquez sur "Enregistrer les modifications"


Étape 2 : Afficher le carrousel
────────────────────────────────────────────────────────────────
➜ Éditez une page ou un article

➜ Ajoutez le shortcode :

   [carrousel_sites]

➜ Publiez !


⚙️ OPTIONS DU SHORTCODE
═══════════════════════════════════════════════════════════════

Shortcode de base :
  [carrousel_sites]

Avec titre personnalisé :
  [carrousel_sites title="Mes Projets"]

Sans défilement automatique :
  [carrousel_sites autoplay="false"]

Avec délai personnalisé (en millisecondes) :
  [carrousel_sites delay="3000"]

Toutes les options :
  [carrousel_sites title="Portfolio" autoplay="true" delay="4000"]


🎨 PARAMÈTRES DISPONIBLES
═══════════════════════════════════════════════════════════════

title     = Titre du carrousel (défaut: "Mes Sites Web")
autoplay  = true/false (défaut: true)
delay     = Délai en ms (défaut: 5000)
